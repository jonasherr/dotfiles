# Jonas writing checklist

Use this checklist when reviewing or polishing content.

## Fast pass

- Lead with the problem and solution.
- Keep the reader's task at the center.
- Use short, active sentences.
- Use `you` for instructions.
- Use `I` only for personal workflow pieces.
- Cut filler, repetition, and throat-clearing.
- Use sentence case headings.
- Add blank lines before bullet lists.
- Remove em dashes in explanations.
- Remove semicolons from lists.
- Remove formal transitions like "furthermore" and "moreover".
- Remove hype words like "game-changing", "revolutionary", "incredible", and "amazing".

## Replace these patterns

| Avoid | Use instead |
|---|---|
| utilize | use |
| initiate | start |
| facilitate | help, make possible |
| due to the fact that | because |
| in order to | to |
| it is important to note that | note that, or cut it |
| the aforementioned | this, that, or name the thing |
| one can | you can |
| deployment can be done | you can deploy |
| furthermore, moreover, additionally | also, or start a new sentence |
| here's the catch | state the issue directly |
| you might wonder | cut it |

## Structure patterns

### Guide

```md
# How to [do the task]

[Problem]. [Solution approach].

## Before you start

...

## Step 1: [specific action]

...

## Why this works

...

## What can go wrong

...
```

### Troubleshooting

```md
# Fix [specific error]

[Error] means [cause]. Fix it by [solution].

## Check [thing]

...

## Why this happens

...
```

### Personal workflow

```md
# How I [do specific workflow]

I wanted [outcome]. The problem was [constraint].

Here's the setup I use.

## What you'll set up

...

## Why this matters

...
```

## Final read-aloud test

Read each paragraph out loud. Rewrite anything that sounds like a brochure, policy doc, or generic AI answer.
